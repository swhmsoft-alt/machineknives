AISI 420 Martensitic Stainless Steel is a reference entry for industrial cutting tools and blades. The composition, hardness, heat treatment and application guidance are summarised below for engineering reference.

**Standard composition:** C 0.15 % min, Cr 12.0–14.0 %, Mn ≤ 1.00 %, Si ≤ 1.00 %, Ni ≤ 0.75 %, balance Fe

**Hardness:** Annealed HB 195–230; hardened HRC 48–54

**Heat treatment:** Austenitise 980–1,030 °C, oil or air cool, temper 150–200 °C

**Properties:** The basic martensitic stainless. Modest hardness (HRC 50) but high corrosion resistance. Tough, easy to grind. The "20" in 420 indicates a 0.20 % C minimum; 420HC at 0.40 % C is a variant for cutlery.

**Applications:** Food processing blades, surgical instruments, pump shafts, valve parts, low-stress cutlery.

**Cross-reference:** ≈ JIS SUS420J1/J2, DIN 1.4021/1.4028, GB 2Cr13/3Cr13.
