# Shear Blade – Guillotine 300 × 60 mm

Industrial shear blade for guillotine and swing-beam cutting of mild steel, stainless steel and aluminium plate up to 12 mm thickness. Manufactured from shock-resistant tool steel, ground to a flatness suitable for plate-edge quality.

## Typical Specifications

| Parameter       | Value                       |
| --------------- | --------------------------- |
| Length          | 300 mm (range 100–1000 mm)  |
| Width           | 60 mm (range 30–200 mm)     |
| Thickness       | 25 / 30 / 40 mm             |
| Bevel angle     | 1.5° / 2° / 3°              |
| Cutting capacity| ≤ 12 mm mild / ≤ 8 mm SS    |
| Flatness        | ≤ 0.02 mm                   |
| Hardness        | HRC 55–60                   |

## Common Materials

- **D2 (1.2379)** — standard for stainless and high-silicon steels, long edge life.
- **6CrW2Si** — Chinese GB grade, shock-resistant, used for swing-beam shears cutting thicker plate.
- **H13 (1.2344)** — hot-work tool steel, used when shear runs hot (high-speed lines, abrasive plate).

## Edge Geometry

Single-bevel or four-edge reversible designs available. Reversible blades double the service life per blade.
